# Critical Reflection Depth — LLM semantic rubric

本尺規用於評估地球物理與地震學數位作品中的**批判反思深度**，而不是作品技術複雜度或反思關鍵詞頻率。

## Level 0 — Non-reflective

純粹呈現學科理論、公式、程式碼、作品功能或一般成果展示，沒有學生自身的觀點、過程紀錄、困難描述或學習反思。

## Level 1 — Descriptive Reflection

學生描述做了什麼、使用什麼工具、參與什麼活動、學到什麼或遇到什麼事情，但沒有深入解釋原因、證據或方法限制。

## Level 2 — Analytical Reflection

學生能進一步分析：

- 問題或結果為何發生；
- 理論與實作／資料為何有差異；
- AI、程式、儀器或分析方法有哪些限制；
- 自身專業背景或學習經驗如何影響理解與判斷。

## Level 3 — Critical & Transformative Reflection

在 Level 2 的分析基礎上，學生能進一步：

- 提出具體可執行的改進方案；
- 依據證據重構後續實作或分析方法；
- 對 AI 輔助、科學資料品質、驗證責任或研究限制形成批判性原則；
- 形成明確的未來學習／實踐策略。

## 判定規則

1. 每份作品記錄**有直接文本證據支持的最高層次**。
2. 「限制」「比較」「為什麼」等詞若只是教材內容，不構成反思。
3. 網站互動程度、程式碼數量、圖表數量不直接影響本分數。
4. 若來源無法讀取學生文本，記為 `NA`，不能記為 Level 0。
5. 評分理由只需提供 rubric-based justification，不需要保存或公開模型內部推理過程。
6. 公開研究資料不得重新提交學生姓名、學號、作品網址或長段原始文本。

## 建議結構化輸出

私人研究工作區可保存：

```json
{
  "quote": "最多兩句代表性原句，若無則為 null",
  "reasoning": "依 rubric 說明為何達此層次，以及尚缺少什麼而未達更高層次",
  "score": 0
}
```

公開 repository 則只保存匿名代碼、score、evidence status、confidence 與 method。
